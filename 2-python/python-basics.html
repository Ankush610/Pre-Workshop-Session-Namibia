Environments: one clean box per project
The problem:
Project A needs pandas 1.5, Project B needs pandas 2.2. Give each its own box.

Built into Python
python -m venv .venv
Simple, nothing extra to install.

Data science favourite

Can also pick the Python version.

New and very fast

Same idea, installs in seconds.

requirements.txt: the shopping list

A simple text file that lists every library your project needs.

PRACTICE & RECAP
Errors are normal (and helpful)
SyntaxError
Python can't read the line.
Missing ), : or a quote
NameError
Python doesn't know that name.
A typo like prnt("hi")
IndentationError
The spaces at the start are wrong.
Indent 4 spaces after a line ending in :
TypeError
Mixing types that don't fit.
"Age: " + 21 → use str(21)
Tip: read the LAST line of the error first.
It names the problem and the line number. Still stuck? Search it online: every programmer does!
