WHAT IS LINUX?
What is an operating system?
The operating system is the manager of your computer.
It sits between you and the hardware. When you open an app or save a file, the OS tells the CPU, memory and disk what to do.
Examples: Windows, macOS, Android and Linux
You & your apps

MEET THE TERMINAL
Clicking vs. typing
GUI · GRAPHICAL USER INTERFACE
You click
  • Icons, windows and menus
  • Easy to start with
  • Slow for repeated tasks
CLI · COMMAND LINE (TERMINAL)
You type
  • Short text commands
  • Fast and very powerful
  • Works on remote servers
$ mkdir photos
Most servers have no screen and no mouse, so the terminal is how we talk to them.

Files and folders
mkdir notes
Make a new folder
touch a.txt
Create an empty file

Copy a file

Move or rename a file

ESSENTIAL COMMANDS · 4 OF 8
Searching: grep and find
grep
looks inside files
Finds lines that contain a word.
$ grep "banana" fruits.txt banana $ grep -i "APPLE" fruits.txt apple
-i ignores upper/lower case · -r searches a whole folder
find
looks for files
Finds files and folders by name.
$ find . -name "*.txt" ./fruits.txt ./notes/todo.txt $ find ~ -name "todo*" /home/student/notes/todo.txt
* is a wildcard: it matches anything

ESSENTIAL COMMANDS · 8 OF 8
Getting help and staying safe
man ls
The full manual for any command. Press q to quit.
ls --help
A shorter, quick summary of the options.
sudo command
"Superuser do": run a command as the administrator. It asks for your password.
GOLDEN RULES
Power tools need care
  • Read a command before you press Enter
  • Use sudo only when you really need it
  • Be extra careful with rm -r
  • Never run commands you don't understand from the internet

VIM BASICS
Vim: a text editor in the terminal
Found on almost every Linux server. Open or create a file with:
$ vim notes.txt
VIM STARTS HERE
Normal mode
Move around and give commands, like save or quit. Typing letters does not add text.
i
→
←
Esc
PRESS i TO ENTER
Insert mode
Type text like a normal editor. You'll see -- INSERT -- at the bottom.
Lost or confused? Press Esc. It always takes you back to Normal mode.

FAQ
Frequently asked questions
Is Linux hard to learn?
No. Start with the commands from today and practise for 10 minutes a day.
Which distro should I start with?
Ubuntu or Linux Mint: beginner friendly, with lots of help online.
Do I have to remove Windows?
No. Try a virtual machine (VirtualBox), WSL on Windows, or dual boot.
Can I break my computer?
Everyday commands are safe. Just be careful with sudo and rm -r.
Is Linux really free?
Yes. Most distros are free to download, use and share.
What should I learn next?
Users and permissions, installing software (apt / dnf) and shell scripts.
Any other questions? Ask away!
